## Русский

Веб-приложение, созданное для изучения основ компьютерных наук, структур данных и алгоритмов, а также интерактивный визуализатор перевода текста в двоичный код[cite: 2].

### Особенности проекта
* **Структуры данных:** Краткая информация и преимущества основных структур (массивы, связанные списки, деревья, графы)[cite: 2].
* **Алгоритмы:** Разбор понятия алгоритма и его четырех основных характеристик[cite: 2].
* **Интерактивный визуализатор:** Конвертирует введенный текст в двоичный (бинарный) код в реальном времени с помощью JavaScript[cite: 2, 4].
* **Адаптивный дизайн:** Сайт полностью оптимизирован для мобильных устройств, планшетов и ПК[cite: 3].

### Используемые технологии
* **HTML5**[cite: 2]
* **CSS3** (Flexbox, Media Queries)[cite: 1, 3]
* **JavaScript** (Обработка событий, манипуляции с DOM, конвертация в бинарный код)[cite: 2, 4]

## English

A web application designed for learning the fundamentals of computer science, data structures, and algorithms, featuring an interactive text-to-binary code visualizer[cite: 2].

### Project Features
* **Data Structures:** Overview and advantages of core structures (Arrays, Linked Lists, Trees, Graphs)[cite: 2].
* **Algorithms:** Explanation of what an algorithm is and its four key characteristics[cite: 2].
* **Interactive Visualizer:** Converts inputted text into binary code in real-time using custom JavaScript[cite: 2, 4].
* **Responsive Design:** Fully optimized for mobile devices, tablets, and desktops[cite: 3].

### Technologies Used
* **HTML5**[cite: 2]
* **CSS3** (Flexbox, Media Queries)[cite: 1, 3]
* **JavaScript** (Event handling, DOM manipulation, binary conversion)[cite: 2, 4]

## Հայերեն

Վեբ հավելված, որը ստեղծված է համակարգչային գիտության հիմունքները, տվյալների կառուցվածքներն ու ալգորիթմները ուսումնասիրելու համար, ինչպես նաև ներառում է տեքստը երկուական (բինար) կոդի փոխակերպող ինտերակտիվ վիզուալիզատոր[cite: 2]:

### Նախագծի հնարավորությունները
* **Տվյալների կառուցվածքներ:** Հիմնական կառուցվածքների (զանգվածներ, ցուցակներ, ծառեր, գրաֆներ) նկարագրությունն ու առավելությունները[cite: 2]:
* **Ալգորիթմներ:** Ալգորիթմի հասկացության և նրա 4 անկյունաքարային հատկանիշների բացատրություն[cite: 2]:
* **Ինտերակտիվ վիզուալիզատոր:** Իրական ժամանակում մուտքագրված տեքստը փոխակերպում է երկուական կոդի JavaScript-ի միջոցով[cite: 2, 4]:
* **Ադապտիվ դիզայն:** Կայքը լիովին հարմարեցված է բջջային սարքերի, պլանշետների և համակարգիչների համար[cite: 3]:
